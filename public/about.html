Core Features

Live Sharing

Share terminal sessions with unique URLs. Perfect for collaboration and remote support.

Persistent Sessions

Sessions survive disconnections and page reloads. Full history preserved.

Cloudflare Tunnels

One-click public URLs for local servers. Share your work instantly.

Smart Port Detection

Auto-detects when you start a server. Pop-up notifications with tunnel options.

Mobile Optimized

Full PWA support. Install as native app. Touch-friendly controls.

Security Levels

Configurable access control: full, limited, or restricted system access.

Installation

Get started in seconds with npx (no installation required):

npx web-terminal-server

Or install globally:

npm install -g web-terminal-server

שיתוף חי

שתף סשנים של טרמינל עם קישורים ייחודיים. מושלם לשיתוף פעולה ותמיכה מרחוק.

סשנים מתמידים

סשנים שורדים ניתוקים ורענון דפים. כל ההיסטוריה נשמרת.

מנהרות Cloudflare

כתובות URL ציבוריות בלחיצה אחת לשרתים מקומיים. שתף את העבודה שלך מיידית.

זיהוי פורטים חכם

מזהה אוטומטית כאשר מפעילים שרת. התראות קופצות עם אפשרויות מנהרה.

אופטימיזציה למובייל

תמיכה מלאה ב-PWA. התקן כאפליקציה מקורית. בקרות ידידותיות למגע.

רמות אבטחה
